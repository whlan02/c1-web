# 歌德 C1 Lesen Teil 1：语法与考点总表

> 目标：把这部分从「语感碰运气」变成「先判词类/句法，再靠上下文」。  
> 依据：`books/` 里全部 **2024 模块化 C1** 教材的 Lesen Teil 1（含 Üben 讲解 + 各 Modelltest 选项页 + Express 带解释的答案）。  
> 考场流程见 `歌德C1考试技巧.md` §2.1；本文只收**必须会的知识**。

---

## 0. 这题到底考什么

- 一篇科普 / 信息类文章，**8 空**，每空 **a/b/c/d**，约 **10 分钟**，8 分。
- 官方能力：词汇 + 语法。选项几乎总是「四个都像对」，差别落在下面几类之一：
  1. **句法位置不对**（连词 / 副词 / 介词混用）
  2. **指代不对**（关系代词、代副词指回什么）
  3. **搭配不对**（介词、Funktionsverbgefüge、固定说法）
  4. **四个都合法 → 看段落意思**（近义动词/形容词）

**Übungsbuch 的硬规则：** 先判断空里要填什么词类 / 什么结构，再选。四个都合法时，看前一句、后一句、该段主旨。

学完本文后，Teil 1 会变成最可训练的一题：大约一半空用语法就能杀掉 2–3 个干扰项，剩下靠搭配和段落意思。

---

## 1. 考场决策树（每空 40 秒）

1. **看空前后各 3–6 个词**：后面有没有已经出现的动词？动词在不在句末？有没有 `zu`？有没有逗号开的从句？
2. **先定词类**（Nomen / Verb / Adj / Adv / Präp / Konnektor / Relativ / Pronominaladverb）。四个选项词类必须相同才进入第 3 步；词类不同时，先按句法排除。
3. **语法筛**：位置、格、单复数、动词配价、关系代词性数格。
4. **搭配筛**：这个动词/名词后面跟哪个介词？有没有固定说法？
5. **意思筛**：只有语法都过关时，才用「这段在讲什么」选。

Beispiel 0 一定要看：它告诉你这篇在考什么风格（经常是介词、Konnektor 或固定动词）。

## 2. 模块 A：三类连接手段（Lesen 1 出现最多）

同一语义（原因、让步、目的……）德语有 **四种外壳**。Lesen 1 最爱把四种放在同一题里让你选「这一格只能用哪一种」。

| 类型 | 位置 | 动词位置 | 典型词 | 不能干什么 |
|---|---|---|---|---|
| **Konjunktor** | 两个主句中间（Position 0） | 两边都是正语序 | `denn`, `aber`, `doch` | 不能把动词踢到句末 |
| **Subjunktor** | 从句句首 | **动词在从句末** | `weil`, `obwohl`, `damit`, `während`, `nachdem`, `sodass` | 空后面如果动词已经在第二位，就不能选它 |
| **Adverb / Konjunktionaladverb** | 新句句首或句中 | 后面仍是 **Verb 第二位**（它自己占第一位时） | `deshalb`, `dennoch`, `trotzdem`, `daher`, `infolgedessen`, `hingegen` | 不能当从句连词 |
| **Präposition / Wendung** | 后面接 **Nomen / Pronomen**（带格） | 不影响动词位置 | `wegen`, `aufgrund`, `trotz`, `dank`, `im Hinblick auf` | 后面不能接完整从句（除非 `trotz der Tatsache, dass`） |

### 2.1 一眼排除的对立组（书里反复出现）

**原因**

| 要填的结构 | 选 | 不选 |
|---|---|---|
| 从句，动词在末 | `weil` / `da` | `denn` / `deshalb` / `aufgrund` |
| 主句+主句，中间解释 | `denn` | `weil`（Express MT2 Beispiel：`…, denn …` 对，`weil` 错，因为后面不是从句语序） |
| 新句开头、因果、Verb 第二 | `deshalb` / `daher` / `darum` / `deswegen` | `weil` / `denn` |
| 名词前 | `aufgrund` + Gen.；`wegen` + Gen.；`durch` + Akk.（手段） | `infolgedessen`（那是副词，后面要接句子） |

**让步 / 对立**

| 结构 | 选 | 陷阱 |
|---|---|---|
| 从句 | `obwohl` / `obgleich` / `wenngleich` | 后面必须动词在末 |
| 新句 / 句中副词 | `trotzdem` / `dennoch` / `jedoch` / `allerdings` | Express MT1：空在新句句首、后面正语序 → `dennoch`，不是 `obwohl` |
| 对比两件事 | `wohingegen`（从句） / `dagegen`（副词） | `wohingegen` 需要从句；`dagegen` 占 Vorfeld |
| 介词 | `trotz` + Gen. | 不能接从句 |

**目的**

| 结构 | 选 | 注意 |
|---|---|---|
| `um … zu` + Infinitiv | 主语与主句相同 | Express MT1：`um … zu`，不是 `damit`（`damit` 要完整从句：`damit sie …`） |
| `damit` + 从句 | 主语可以不同 | 空后如果已经是 `zu` + Inf.，不能选 `damit` |
| `für` + Nomen | 目的名词 | 空后是动词不定式时不选 |
| `dazu` / `dafür` | 代副词，指回前面的目的 | 见模块 C |

**时间**

- 从句：`als`（一次性过去）、`wenn`（重复/将来）、`während`（同时）、`nachdem`（之后，注意完成时）、`bevor` / `ehe`、`seit` / `seitdem`、`sobald`、`solange`
- 副词：`danach`、`davor`、`vorher`、`währenddessen`、`anschließend`
- 介词：`beim` + Inf./Nomen、`während` + Gen.、`nach`、`vor`、`seit`

Lesen 1 常把 `bevor`（连词）和 `davor` / `vorher`（副词）放一起。看后面是从句还是已经有定式动词。

**条件**

- `wenn` / `falls` / `sofern` = 从句
- `ob` = 间接问句「是否」，不是条件
- `als` 在 C1 科普文里常是比较（`größer als`）或过去时间，很少当条件

### 2.2 必须会背的 Konnektoren 表（Express Anhang）

按语义记「四种外壳各一个」：

| 语义 | Konjunktor | Subjunktor | Adverb | Präp / Wendung |
|---|---|---|---|---|
| 原因 | `denn` | `weil`, `da` | `deshalb`, `daher`, `darum`, `deswegen` | `wegen`, `aufgrund`, `angesichts`, `dank` |
| 结果 | — | `sodass`; `so …, dass` | `folglich`, `infolgedessen` | `infolge` |
| 对立 | `aber`, `doch` | `während`; `anstatt dass` | `jedoch`, `dagegen`, `hingegen` | `im Gegensatz zu`, `im Vergleich zu` |
| 条件 | `vorausgesetzt` | `wenn`, `falls`, `sofern` | `andernfalls`, `sonst` | `ohne`; `im Falle von` |
| 让步 | `zwar … aber` | `obwohl`, `auch wenn` | `trotzdem`, `dennoch`, `allerdings` | `trotz`, `ungeachtet` |
| 目的 | — | `damit`; `um … zu` | `dazu`, `dafür` | `für`, `zwecks`, `zu` |
| 手段 | — | `indem`; `dadurch, dass`; `ohne zu` | `dadurch`, `damit` | `durch`, `mit`, `mittels` |
| 同时 | — | `während`, `indem` | `währenddessen` | `während` |
| 先后 | — | `bevor`, `nachdem`, `sobald` | `danach`, `davor`, `anschließend` | `nach`, `vor`, `seit` |

### 2.3 双件套 Konnektoren（Übungsbuch Grammatik 4）

偶尔作为选项或帮助你读懂空前后：

- `zwar … aber` / `zwar … jedoch`
- `einerseits … andererseits`
- `nicht nur … sondern auch`
- `sowohl … als auch`
- `weder … noch`
- `entweder … oder`
- `je … desto` / `je … umso`
- `wenn … so` / `wenn … dann`

空里只给一半时，看另一半是否已经出现。

## 3. 模块 B：关系代词 Relativpronomen

几乎每套 Modelltest 都有 1 题。

### 3.1 先判先行词

| 先行词 | 常用关系词 |
|---|---|
| 人 / 具体名词（der/die/das） | `der / die / das`（随格变：`dem`, `den`, `deren`, `dessen`） |
| 整句话 / 不定内容 / `etwas`, `nichts`, `das`（指前面整句） | **`was`** |
| 地点 | `wo` / `in dem` |
| 介词 + 物 | `wo(r)+Präp`：`worin`, `womit`, `wodurch`, `worauf` |
| 介词 + 人 | `Präp + Relativ`：`mit dem`, `über die` |

Testbuch MT1 Beispiel：`…, was` 指前面整件事，不是 `dass`（`dass` 开宾语从句，不是关系从句），也不是 `die`（没有阴性先行词）。

### 3.2 Genitiv：`dessen` / `deren` / `derer`

这是 C1 高频坑。

- **`dessen`**：先行词是 **阳性或中性单数**（der Mann, das Team, das Unternehmen）
- **`deren`**：先行词是 **阴性单数或所有复数**（die Studie → deren Ergebnisse；die Menschen → deren …）
- **`denen`**：复数 **Dativ**（`bei denen`, `von denen`），不是属格
- **`seine` / `ihre`**：人称代词，前面通常**不能**再当关系词用（关系从句要用 `dessen/deren`）
- **`derer`**：较少，指「那些人的」，且往往不带紧跟的名词；Lesen 1 里见到优先怀疑，先核对是否该用 `dessen`

Express MT1：`deren` 修饰复数/阴性先行词的属格，不是 `dessen`，更不是 `seine`。

Projekt MT5 类选项：`mit deren Hilfe` vs `die mit Hilfe` vs `durch die Hilfe`  
→ 先行词属格 + 固定说法 `mit Hilfe` = **`mit deren Hilfe`**。

### 3.3 `wer` / `was` / `welcher`

- 句首、没有先行词、泛指「谁……谁就……」：`Wer …, (der) …`（Projekt MT4 Beispiel）
- `welcher` 很少作关系词（书面、避免重复 `der` 时才用）；选项里出现时多数是干扰
- `was für` 不是关系代词

## 4. 模块 C：代副词 Pronominaladverb / Präpositionalpronomen

形式：`da(r)-` / `hier-` / `wo(r)-` + 介词。**只指物或整件事，不指人。**

### 4.1 先找回动词/名词的固定介词

空选 `davon / dafür / dagegen / daraus …` 时，不要猜意思，先找 **配价**：

| 常见配价 | 代副词 |
|---|---|
| `versprechen von` / `die Rede von` / `bestehen aus` / `sich zusammensetzen aus` | `davon` / `daraus` |
| `sorgen für` / `sich eignen für` / `Argument für` | `dafür` |
| `sich wehren gegen` / `sprechen gegen` | `dagegen` |
| `abhängen von` | `davon` |
| `führen zu` | `dazu` |
| `sich erinnern an` / `denken an` | `daran` |
| `sich freuen auf` / `warten auf` / `hinweisen auf` | `darauf` |
| `sprechen über` / `sich informieren über` | `darüber` |
| `leiden unter` | `darunter` |

Express MT1：`Davon versprechen sich Experten …` → 动词是 `sich etwas von etwas versprechen`，所以是 **`davon`**，不是 `dafür/dagegen/danach`。

### 4.2 `hier-` 系列

科普文喜欢用 `Hierbei`（在这件事上）、`Hieraus`（由此得出）、`Hierfür`。  
看它指的是「过程中 / 从中得出 / 为了这个」。

Testbuch MT1：`Hierbei` vs `Hieraus` vs `Währenddessen` vs `Wobei`  
- `wobei` 开从句；`währenddessen` 表同时；`hieraus` = 从前面的事实推出结论。

### 4.3 问句型 `wo(r)-`

`wodurch`（凭借什么手段）、`womit`、`worin`、`weshalb`（为何）。  
`somit` / `sodass` 不是代副词：`somit` = 因此（副词），`sodass` = 以至于（从句连词）。

## 5. 模块 D：不定式、可分动词、词类

### 5.1 `um … zu` / `ohne … zu` / `anstatt … zu`

- 主语与主句相同才用。
- 可分动词：`um … vorzubereiten`（前缀贴不定式）。
- 选项陷阱：`um zu geben`（错拆）、`umgeben`（过去分词/不定式粘在一起）、`umzugehen`（可分动词 `umgehen` 的 zu-不定式）、`zu umgehen`（不可分 `umgehen` = 避开）。

Testbuch MT3 第 7 题就是这一组：必须能判断这个动词此刻是 **可分** 还是 **不可分**。

### 5.2 可分前缀改变词义（Beispiel 常考）

Express MT1 Beispiel：`hat … ausgedient`（过时、不再被用）≠ `aufgehört`。  
先看完成时里前缀有没有贴在分词上：`ausgedient`, `angefangen`, `zugenommen`。

### 5.3 Partizip I / II / Gerundiv / 不定式（Übungsbuch Schmerzmittel / Solar-LKW）

同一词干四个壳：

| 形式 | 功能 | 例子 |
|---|---|---|
| Infinitiv | 动词 | `beobachten` |
| Partizip I | 进行中的形容词 | `beobachtend` |
| Partizip II | 完成/被动形容词 | `beobachtet` |
| `-bar` | 可能性 | `beobachtbar` |
| Gerundiv `zu` + Partizip I | 必须被……的 | `die auszulösenden Schmerzen` |

空在名词前 → 只能是形容词/分词，不能是原形动词。

### 5.4 词类伪装

Übungsbuch 明确练过：

- `daneben`（副词） / `Nebenrolle`（名词） / `nebenbei`（副词） / `nebensächlich`（形容词）
- 空在 `ein sehr ___ Problem` → 必须是 Adj，不是 Nomen。

先看空的句法槽，再看词义。

## 6. 模块 E：介词 + 格 + 近义介词

选项经常是 `an / mit / über / von / für / zu / durch`。

### 6.1 先背「动词/名词要哪个介词」，不要靠翻译

高频（Lesen 1 选项页反复出现）：

| 搭配 | 介词 | 格 |
|---|---|---|
| `im Hinblick auf` | `auf` | Akk. |
| `sich unterscheiden von` / `die Rede von` / `abhängig von` | `von` | Dat. |
| `bestehen aus` / `sich zusammensetzen aus` | `aus` | Dat. |
| `führen zu` / `beitragen zu` / `im Vergleich zu` | `zu` | Dat. |
| `warnen vor` | `vor` | Dat. |
| `denken an` / `erinnern an` / `Mangel an` | `an` | Akk. 或 Dat.（看动词） |
| `informieren über` / `diskutieren über` | `über` | Akk. |
| `sich beschäftigen mit` / `im Zusammenhang mit` | `mit` | Dat. |
| `durch` = 手段/被动施事 | `durch` | Akk. |
| `dank` / `aufgrund` / `wegen` | 原因 | 通常 Gen. |
| `trotz` | 让步 | Gen. |
| `zwecks` / `mittels` / `anlässlich` | 书面介词 | Gen. |

Projekt MT3：`zwecks`（目的） vs `mittels`（手段） vs `anlässlich`（值某活动之际） vs `dank`（多亏）——四个都是介词，**语义**不同，语法都对。

### 6.2 时间介词 vs 连词

Testbuch MT2 Beispiel：`beim` + 名词/动名词，不是 `nachdem`/`während`/`wegen`。  
空后是名词 → 介词；空后是主语+动词 → 连词。

## 7. 模块 F：Funktionsverbgefüge 与固定说法

科普书面语大量使用「名词承担词义 + 虚义动词」。Lesen 1 会给四个都像动词或四个都像介词短语。

### 7.1 结构

- **Nomen + Verb**：`Hilfe leisten`, `eine Entscheidung treffen`, `Einfluss nehmen`, `Kritik üben`
- **Präp + Nomen + Verb**：`zum Einsatz kommen`, `in Anspruch nehmen`, `zur Verfügung stehen`, `in Kontakt treten`, `zur Ruhe kommen`, `in Gang kommen`

动词本身几乎没词义，**不能随意替换**近义动词。

Express MT2 Beispiel：`eine Entscheidung treffen`（不是 `geben/machen/wählen`）。

### 7.2 书里出现过的固定组（建议整组背）

| 正确 / 常考 | 干扰 |
|---|---|
| `im Hinblick auf` | `hinsichtlich` 虽对但选项里常是 `im Hinblick` 缺 `auf` |
| `gang und gäbe`（司空见惯） | `im Gange`, `in Gang gekommen`, `unter die Haut gegangen` |
| `in Anspruch nehmen` | `zur Entscheidung` / `zur Kenntnis`（意思不同） |
| `zur Verfügung stehen/stellen` | 同上 |
| `ab und zu` / `hin und wieder` | `hin und her`, `an und aus` |
| `Studie / Untersuchung belegt` | `bezeugt`, `erzeugt`, `schreibt` |
| `Aufgaben erledigen` | `ergänzen`, `erstellen`, `erzeugen` |
| `Reichweite ist begrenzt` | 语法都对时看段意 |
| `Strom erzeugen` | 不是随便 `herstellen` |

## 8. 模块 G：近义词——语法过关后才看段意

Übungsbuch Solar-LKW 的课就是这个：四个形容词都合法，必须读该段在强调什么。

方法：

1. 标出该段 1 个关键词（Treibhausgas / Unfall / Gewicht / Reichweite）。
2. 选与这个关键词同向的选项。
3. 不要选「世上也说得通但本段没说」的词。

书里反复出现的近义场（背差异，不背中文）：

**动词**

| 词 | 典型对象 |
|---|---|
| `erledigen` | Aufgaben, Arbeit |
| `erstellen` | Bericht, Gutachten, Liste |
| `erzeugen` | Strom, Energie, Produkte |
| `ergänzen` | 补全已有之物 |
| `belegen` | Studie belegt eine These |
| `erweitern` | Angebot, Wissen |
| `verbreiten` | Nachricht, Virus, Brauch |
| `verdrängen` | 挤掉、取代 |
| `verbannen` | 驱逐（过强，常错） |
| `übersteigen` | Zahl, Wert（超过数值） |
| `überschreiten` | Grenze, Tempo（越过界限） |
| `überwinden` | Hindernis, Krise |
| `umgehen`（不可分） | 避开规则/问题 |
| `umgehen mit`（可分） | 对待、处理 |

**名词**

| 组 | 差在哪 |
|---|---|
| `Mischung` / `Gemisch` / `Vielfalt` / `Vermengen` | 混合物 vs 多样性 vs 动词名词化 |
| `Ergebnis` / `Ertrag` / `Ernte` / `Erlös` | 结果 / 收成收益 / 收获 / 变现款 |
| `Gegensatz` / `Unterschied` / `Kontrast` / `Zwiespalt` | 对立 / 差异 / 对照 / 内心分裂 |
| `Art` / `Eigenschaft` / `Eigenart` / `Kategorie` | 种类 / 属性 / 独特性 / 分类 |

**形容词 / 程度**

| 组 | 用法 |
|---|---|
| `gängig`（常见的） / `gangbar`（行得通的路） / `angehend`（即将成为） | 不要看长得像 |
| `kaum` vs `fast` | `kaum` = 几乎不；`fast` = 几乎是 |
| `ganz` / `gar` / `völlig` / `insgesamt` | `gar nicht`；`insgesamt` = 总共 |
| `klimafreundlicher` vs `leistungsstärker` | 看本段强调排放还是性能 |

**情态 / 助动词**

空是 `haben / hatten / müssten / waren` 或 `hat / kann / war / wird` 时：  
看时间（研究已经做完还是预测）、看被动态（`werden` + Partizip II）、看情态（可能性 vs 事实）。

## 9. 模块 H：比较、举例、程度

- 比较：`als`（不同级：`größer als`）、`wie`（同级：`so … wie`）
- 举例：`beispielsweise`, `etwa`, `wie`（`wie z. B.`）  
  Testbuch MT1：空若是插入举例，`beispielsweise` / `etwa` 可能都对，再看标点和是否已有 `wie`。
- 程度副词：`besonders`, `zunehmend`, `wesentlich`, `deutlich` —— 空在形容词前。

## 10. 每空自检清单（建议复印到考场心态里）

空填进去之后，大声（心里）读这一句，五问：

1. 动词在不在它该在的位置？（第二位还是从句末）
2. 这个词是连词、副词还是介词？后面接的是句子还是名词？
3. 关系词 / 代副词指回的那个词，性数格对不对？指人还是指物？
4. 动词/名词的固定介词对不对？
5. 若 1–4 都过关：这一段的主旨支持这个词吗？

有一个「否」就换选项。

## 11. 建议学习顺序（按性价比）

1. **三类连接手段**（本文 §2）+ 把 Express 那张表背熟。用任意一篇 Lesen 1，只做「连词/副词/介词」那几空，直到正确率稳定。
2. **`dessen/deren/denen/was`**（§3）+ **`da(r)+Präp`**（§4）。这两类几乎每套必有。
3. **`um zu` / 可分动词 / Partizip**（§5）。
4. **Funktionsverbgefüge 清单**（§7）+ 介词配价（§6）。
5. 最后才刷近义词（§8）：做题时强制写「本段关键词」，禁止只看中文意思。
